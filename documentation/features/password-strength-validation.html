verify-master

🔐 Password Strength Validation

Validate password strength using uppercase, lowercase, number, special character, and length rules.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validateStrengthPassport } from "verify-master";

const result = validateStrengthPassport("Password@123");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Password is strong enough",
  data: "Success",
  errors: null
}

❌ Invalid Password Example


const result = validateStrengthPassport("password");

console.log(result);



{
  success: false,
  code: 400,
  message: "Password must contain at least one uppercase letter",
  data: null,
  errors: null
}

📋 Validation Rules

  • Password must be a string
  • Password must contain at least one uppercase letter
  • Password must contain at least one lowercase letter
  • Password must contain at least one digit
  • Password must contain at least one special character
  • Password length must be at least 8 characters
