📱 Phone Validation

Validate international phone numbers with country-specific rules.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validatePhone } from "verify-master";

const result = validatePhone("+94771234567", "LK");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Valid phone number",
  data: "+94771234567",
  errors: null
}

❌ Invalid Phone Example


const result = validatePhone("12345", "LK");

console.log(result);



{
  success: false,
  code: 400,
  message: "Invalid phone number format",
  data: null,
  errors: null
}

📋 Validation Rules

  • Phone number must be a string
  • Supports country-based validation (ISO code)
  • Spaces, dashes, dots, brackets are automatically removed
  • Must match country-specific numbering rules
  • Falls back to general international format if country is not provided
