verify-master

💳 Bank Card Type Validation

Detect global debit and credit card types using card number patterns.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validateBankCardType } from "verify-master";

const result = validateBankCardType("4111111111111111");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Valid card type",
  data: {
    cardNumber: "4111111111111111",
    cardType: "Visa"
  },
  errors: null
}

❌ Invalid Card Example


const result = validateBankCardType("9999999999999999");

console.log(result);



{
  success: false,
  code: 400,
  message: "Unknown card type",
  data: null,
  errors: null
}

📋 Validation Rules

  • Card number must be a string
  • Card type is detected using BIN/prefix patterns
  • Supports major global credit & debit card networks
  • Returns detected card type with card number
  • Unknown patterns return validation failure
