verify-master

🚗 Driving Licence Validation

Validate driving licence numbers across 200+ countries using regex-based rules.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validateDrivingLicence } from "verify-master";

const result = validateDrivingLicence("B1234567", "LK");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Valid driving licence number",
  data: "B1234567",
  errors: null
}

❌ Invalid Example


const result = validateDrivingLicence("INVALID123", "LK");

console.log(result);
            

{
  success: false,
  code: 400,
  message: "Invalid driving licence number format",
  data: null,
  errors: null
}

📋 Validation Rules

  • Input must be a string
  • Whitespace is automatically trimmed
  • Input is converted to uppercase
  • Country-specific validation is applied if provided
  • Fallback to DEFAULT pattern if country is not provided
  • Supports 200+ country driving licence formats
