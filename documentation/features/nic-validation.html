🆔 NIC Validation

Validate National Identity Card formats across multiple countries with strict rule-based patterns.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validateNic } from "verify-master";

const result = validateNic("199912345678", "LK");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Valid NIC",
  data: "199912345678",
  errors: null
}

❌ Invalid NIC Example


const result = validateNic("abc123", "LK");

console.log(result);



{
  success: false,
  code: 400,
  message: "Invalid NIC format",
  data: null,
  errors: null
}

📋 Validation Rules

  • NIC must be a string
  • Whitespace is trimmed automatically
  • Supports country-specific NIC formats
  • Strict pattern matching per country rules
  • Fallback validation applied when country is not provided
  • Supports mixed numeric and alphanumeric formats
