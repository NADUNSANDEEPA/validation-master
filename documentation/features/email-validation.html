verify-master

📧 Email Validation

Validate email addresses quickly and consistently.

📦 Installation


npm install verify-master

🚀 Basic Example


import ValidationMaster from "verify-master";

const result = ValidationMaster.email("test@gmail.com");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Email is valid",
  data: null,
  errors: null
}

❌ Invalid Email Example


const result = ValidationMaster.email("testgmail.com");

console.log(result);



{
  success: false,
  code: 400,
  message: "Invalid email format",
  data: null,
  errors: null
}

📋 Validation Rules

  • Email must be a string
  • Email must contain @
  • Email must contain valid domain
  • Spaces are not allowed
