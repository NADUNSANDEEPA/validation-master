verify-master

🆔 Random ID Generator

Generate unique IDs using prefixes, numeric patterns, and alphanumeric formats.

📦 Installation


npm install verify-master

🚀 Basic Example


import { generateRandomId } from "verify-master";

const result = generateRandomId("EMP", 6, "NUMBER");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Random ID generated successfully",
  data: {
    id: "EMP123456"
  },
  errors: null
}

⚙️ ID Generation Types

  • NUMBER → Only numeric characters
  • NUMBER_AND_LETTER → Alphanumeric (base36)
  • Default → Alphanumeric fallback

🧪 Example Outputs

Input Output Example
generateRandomId("EMP", 6, "NUMBER") EMP123456
generateRandomId("USR", 8, "NUMBER_AND_LETTER") USRa9k2x1p7
generateRandomId(null, 5) abc12
generateRandomId(123, 6, "NUMBER") ID123456

📋 Rules

  • Prefix is optional
  • Non-string prefix defaults to "ID"
  • Supports numeric and alphanumeric generation
  • Length defines random part only
  • IDs are randomly generated (non-cryptographic)
