🛂 Passport Validation

Validate passport numbers using country-specific formats with fallback support.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validatePassport } from "verify-master";

const result = validatePassport("N1234567", "LK");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Passport is valid",
  data: "N1234567",
  errors: null
}

❌ Invalid Passport Example


const result = validatePassport("123", "LK");

console.log(result);



{
  success: false,
  code: 400,
  message: "Invalid passport format",
  data: null,
  errors: null
}

📋 Validation Rules

  • Passport must be a string
  • Spaces and dashes are automatically removed
  • Input is normalized to uppercase
  • Country-specific validation rules applied if provided
  • Fallback pattern used if country is not supported
  • Supports global passport formats (DEFAULT rule)
