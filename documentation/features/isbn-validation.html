📚 ISBN Validation

Validate ISBN-10 and ISBN-13 using real-world check digit algorithms and format rules.

📦 Installation


npm install verify-master

🚀 Basic Example


import { validateIsbn } from "verify-master";

const result = validateIsbn("9780306406157");

console.log(result);

✅ Success Response


{
  success: true,
  code: 200,
  message: "Valid ISBN",
  data: {
    isbn: "9780306406157",
    type: "ISBN-13",
    valid: true
  },
  errors: null
}

❌ Invalid ISBN Example


const result = validateIsbn("1234567890");

console.log(result);



{
  success: false,
  code: 400,
  message: "Invalid ISBN check digit",
  data: {
    isbn: "1234567890",
    type: "ISBN-10",
    valid: false
  },
  errors: null
}

📖 Supported ISBN Types

  • ISBN-10 → Legacy format (10 characters, may end with X)
  • ISBN-13 → Modern format (978 / 979 prefix)
  • Supports hyphens and spaces (auto normalized)
  • Check digit validation included

📋 Validation Rules

  • Input must be a string
  • Hyphens and spaces are ignored
  • ISBN-10 supports 'X' as check digit
  • ISBN-13 uses Mod-10 algorithm
  • Invalid format returns error response
